# Агенты Mastra

## Recruiting Agent

**Описание:**
Агент для поиска и анализа публичной информации о технических кандидатах (React-разработчиках с 5+ годами опыта и Next.js).

**Функционал:**
- Поиск кандидатов через публичные источники (GitHub, portfolio, Stack Overflow, публичные резюме)
- Анализ публичных страниц кандидатов
- Извлечение навыков, опыта, проектов, location
- Сравнение с требованиями
- Создание shortlist кандидатов

**Используемые инструменты:**
- `webSearchTool` – поиск кандидатов по публичным данным
- `webFetchTool` – извлечение информации с найденных страниц
- `askUserTool` – взаимодействие с пользователем

**Примеры промтов:**
- Найди 5 React разработчиков с 5+ годами опыта и Next.js
- Найди Senior React Developer с React, Next.js и TypeScript
- Найди Frontend Developer с опытом Next.js для remote работы

## Interview Agent

**Описание:**
Агент для проведения технических интервью React-разработчиков.

**Функционал:**
- Генерация вопросов по React, Next.js, TypeScript
- Оценка ответов кандидата
- Создание отчета с оценкой и рекомендациями

**Используемые инструменты:**
- `askUserTool` – взаимодействие с пользователем
- `webFetchTool` – получение данных

**Примеры промтов:**
- Проведи техническое интервью с кандидатом Иваном Ивановым
- Сгенерируй вопросы для React-разработчика с 5+ годами опыта
- Оцени ответы кандидата на вопросы по React и Next.js
